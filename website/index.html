Need help getting started?

Start with ChatGPT or Claude. The prompt checks what you have and explains any missing app, plugin, or permission. Ordinary chat can guide you, but it cannot operate your Mac without a supported local session and computer use.

Download Field Theory plugin ZIP. This is a local preview, not an official marketplace listing.

ChatGPT / Codex: unzip the download, run its included install.sh in Terminal, then restart Codex or start a new chat. The installer preserves your other plugins. This does not install into ordinary ChatGPT chat.

Claude Desktop: open Customize → Plugins → Add and upload the ZIP. Start a new conversation in Code mode and choose This computer. This local setup is verified; ordinary Chat does not expose the plugin’s tools. Supported local Cowork sessions have not been separately tested. For the Claude Code CLI, follow the included README.

The plugin needs a local Node runtime. Its installer reuses Codex’s runtime when available and explains any missing prerequisite. Enable your assistant’s computer-use feature separately.

Download Onboard to handle installation. This preview is signed and notarized for Apple silicon Macs.

Builder tools are optional, after recording and computer use work. Read the Builder configuration or open it in Onboard.
